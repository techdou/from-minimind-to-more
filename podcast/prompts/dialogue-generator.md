# 播客脚本生成 Prompt

## 角色

- **苏打**(主讲,男声沉稳):大模型领域研究者,负责讲解知识点,把控节奏
- **茉莉**(提问者,女声活泼):代表初学者提问、追问、确认理解

## 目标

把一篇技术长文浓缩成 5-8 分钟的双人对话播客。不是念稿,是**真实的知识对话**——两个有思想的人在讨论一个话题。

## 结构(总时长 5-8 分钟)

1. **开场**(20-30 秒):茉莉引入话题 + 苏打一句话定位
2. **知识块 ×3-5**(每个 1-1.5 分钟):
   - 苏打讲解核心概念(用比喻,不用术语堆砌)
   - 茉莉提出疑问/追问("等一下,那...怎么办?")
   - 苏打深入解答
3. **总结**(20-30 秒):苏打收束 + 茉莉一句话感悟 + 预告下一篇

## 对话风格要求

### 必须做到
- **自然口语**:用"你看""其实""换句话说"等口语连接词,不要书面语
- **有来有往**:茉莉不是捧哏,要提真实疑问("这里我没跟上,为什么...")
- **比喻优先**:抽象概念用日常比喻(如"归一化就像调音量")
- **保留术语**:提比喻后点明专业术语,让听众学到正确的词

### 避免
- 机械交替("接下来我来讲..." → "好的请你讲")
- 念课本式独白(苏打一段超 4 句必须被茉莉打断)
- 无意义附和("嗯""对""有道理")
- 考点罗列(播客是理解,不是背诵)

## 输出格式

```json
{
  "title": "文章标题",
  "slug": "article-slug",
  "duration_estimate": "6分钟",
  "dialogue": [
    {
      "speaker": "茉莉",
      "voice": "mimo_v_moli",
      "text": "对话内容",
      "emotion": "好奇"
    },
    {
      "speaker": "苏打",
      "voice": "mimo_m_suda",
      "text": "对话内容",
      "emotion": "平静"
    }
  ]
}
```

### 字段说明
- `speaker`: 显示名(茉莉/苏打)
- `voice`: MiMo TTS 音色 ID(茉莉=`mimo_v_moli` 对应预设"茉莉",苏打=`mimo_m_suda` 对应预设"苏打")
- `text`: 这一段的台词(2-4 句,不要太长)
- `emotion`: 情绪标签(好奇/平静/恍然大悟/强调/轻松),用于 MiMo TTS 的音频标签控制

## 从文章提取的输入

会提供:文章标题、学习目标(objectives)、考点(keypoints)、引言摘要。基于这些浓缩成对话,不要试图覆盖全文所有细节。
